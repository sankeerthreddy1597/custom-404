## 📘 Next.js Demo – Home Page + Custom 404 Page

This project is a minimal Next.js demo showcasing:

- A Home Page with a button that sends users to a random, non-existent route

- A fully customized 404 Not Found Page

- Styled with Tailwind CSS v4 and shadcn/ui

- Icons from lucide-react

This repo demonstrates how to build simple page animations, custom theming, and programmatic navigation inside the App Router.

## 🚀 Features

### 🏡 Home Page

- Clean hero layout

- Hover animations

- “Go Nowhere” button

- Programmatically redirects to a random path (e.g., /explore/xyz123)

### ❌ Custom 404 Page

- Fully styled error page

- Smooth animations

- Friendly messaging

- A button to return home

Perfect for beginners learning the App Router or anyone wanting an example of a styled Next.js 404 experience.
